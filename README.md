# Week-7-8-Lux-Python.Json-Project
# Data Analysis Projects

A collection of data analysis projects covering student records, employee data, vehicle registrations, and user profiles — analyzed with Python, Pandas, and Jupyter.

## 📁 Repository Structure
```
├── data/
│   ├── studentdata.csv
│   ├── stud_data.csv
│   ├── kenyadata.json
│   └── dummy_data.csv
├── analysis.ipynb
└── README.md
```

## 🗂️ Datasets

### 1. Student Data (`studentdata.csv`)
100 student records with `student_id`, `first_name`, `last_name`, `age`, and `gender`.

### 2. Employee Data (`stud_data.csv`)
Employee records with `first_name`, `last_name`, `department`, `salary`, and `employee_id`.

### 3. Kenya Vehicle Registrations (`kenyadata.json`)
Vehicle records including make, model, year, color, VIN, and owner details.

### 4. User Profiles (`dummy_data.csv`)
Rich user profiles with demographics, contact info, employment, banking, and crypto wallet details.

## 🔍 Analysis
- Exploratory data analysis (EDA) on each dataset
- Demographic breakdowns (age, gender, department)
- Data cleaning and type handling
- Visualizations with Matplotlib & Seaborn

## 🛠️ Setup
```bash
pip install pandas matplotlib seaborn jupyter
jupyter notebook analysis.ipynb
```
